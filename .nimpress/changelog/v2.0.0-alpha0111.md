A disciple built a user's profile link itself from `SAUTH_ENDPOINT` and a literal `/u/`, and samna_auth wrote the same literal twice. The link now comes from the middleware. A profile can resolve by a username, so the prophet gains one per app that is unique and reserved by the user, while every link still carries the user id.

## The schema

- `idx_samna_user_app_user_name`, a unique index on `claimius.samna_user (app_id, lower(user_name))` over live rows, in the prophet baseline. The disciple replica carries no such index: the prophet refuses a duplicate before the sync carries it.
- `claimius.get_user_name_available(p_app_id, p_user_name)` answers whether no live user of the app holds the name, ignoring case.
- `claimius.update_user_name(p_app_id, p_user_id, p_user_name)` reserves the name for the user in the app, or releases it when null. `P0404` for a user with no live row in the app, `22023` for a malformed name, `23505` when another user of the app holds it.
- A name is 3 to 32 lower case letters, digits, `_` and `-`, starting with a letter, so it never reads as a user id or as `me`.
- `claimius.upsert_app_user` gives `p_user_name` to a new row only when no live row of the app holds it, so a login carrying a name taken in that app still gets its row.
- `claimius.merge_user` removes the source row before its fields move onto the target, so a source holding a name hands it over.

## The routes

- `GET /sam/user_name?user_name=<name>` answers `{"user_name", "available"}`; `400` for a malformed name.
- `PUT /sam/user_name` with `{"user_id", "user_name"}` reserves for the user in the calling app and answers the body with the name; a null `user_name` releases it. `409` when taken, `404` for a user with no row in the app, `400` for a malformed name.

## Go

- `shared.GetProfileLink(userID)` returns `SAUTH_ENDPOINT` + `/u/` + the user id; `disciple/sdb.GetProfileLink` exports it.
- `(*shared.DB).GetUserNameAvailable(ctx, ac, userName)` returns `*UserNameAvailable`, and `(*shared.DB).PutUserName(ctx, ac, BodySamUserName)` the reserved name or nil on a release, both routed to the prophet; only the user reserves a name for itself.
- `shared.ErrBadUserName` and `shared.ErrUserNameTaken`, exported from `disciple/sdb` with `BodySamUserName` and `UserNameAvailable`.
- `prophet/sdb.GetUserNameAvailable` and `prophet/sdb.PutUserName` for samna_auth itself.

## TypeScript

No change: the routes are app to prophet calls and no browser builds the link.
