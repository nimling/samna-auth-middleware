## Login redirect follows SAUTH_REDIRECT_URI

An unauthenticated browser navigation was sent to the fixed path `/api/sauth/login`. It now goes to the `login` path beside the path of `SAUTH_REDIRECT_URI`, so `https://host/api/auth/callback` sends it to `/api/auth/login`. With no redirect URI the middleware answers 401 instead of redirecting.

## Default base path

The bff `BasePath` default and the browser `getBffPath` default move from `/api/sauth` to `/api/auth`.
