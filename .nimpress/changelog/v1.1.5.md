## One line for every consumer

Bookable ran the 1.0 line with a vendored claimius tree, and Nimployer and Samna Auth ran the 1.1 split. The split is now the only line. Everything Bookable relied on from its copy moved into both role SQL sets and the Go surface, and each consumer pulls the schema as git includes at the ref its `go.mod` pins.

## Access

`mutation_access`, `resolve_access` and `get_user_access` take the object as text and resolve it across its accepted forms inside the query. `get_direct_access` carries a required mask and a raise flag, so `mutation_access` answers 403 or 404 in one round trip. `UserAccess` takes the target as a string, external id, user id or row id, and returns `ErrNotFound` for an unknown user. `RootAccess` skips a soft deleted root.

## Graphs

`get_owner_graph` and `get_claim_graph` page a wide level with `p_width`, `p_sort` and `p_next_id`, and `GraphWindow` carries the three through Go. `object_usage` and `PostObjectUsage` record what an actor opens, which the `usage` sort orders by.

## Writes

Updates and deletes take the record id from the model for every routed claimius type, so a builder with only `.Model(m).Access(ac)` reaches the right prophet path. A root organization keeps the id it was given and is never bound to the actor's claim; its owner claim is created for it. The prophet's organization listing is scoped through `app_object`.
