## Location and relation updates reach the prophet

A disciple sends every routed update as `PATCH` to the record path. The prophet registered `PATCH` beside `PUT` for user, organization, claim, client and secret, but only `PUT` for `location/:id` and `relation/:id`, so a location or relation update from a disciple was refused with 405 before any handler ran. Both now answer `PATCH` through the same handler as `PUT`.

A test in `prophet/sam` derives every path a disciple writes to from `EndpointFor` and fails when the prophet does not register the method for it, so a routed type can no longer drift from the prophet's route table.

## Docs

The module publishes `.nimpress` to the docs site under Auth Middleware: the two roles, the disciple write and sync path, and the access lookups.
